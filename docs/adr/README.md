# Architectural Decision Records

Each ADR records one specific, adjudicated architectural decision —
narrower than an `architecture-notes/` file, which covers a whole
document's rationale and history. An ADR exists once a decision has
actually been ruled on; proposals under evaluation stay in review
deliverables until they're accepted or rejected, not here.

Status values used: **Proposed** (drafted, awaiting explicit
confirmation), **Accepted** (ruled on, in effect), **Superseded**
(replaced by a later ADR, linked from both).

Start with `0000-architectural-governance.md` — it defines the roles,
the RAE Cycle, and how authority is distributed across the documents
in this repo; everything else here operates under it.
